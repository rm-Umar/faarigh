# فارغ (Faarigh) — App Design Brief

## The App
**فارغ (Faarigh)** — Urdu for "free/unburdened." A premium all-in-one digital wellbeing app for Android. Combines screen time tracking, app interception, content filtering, ad blocking, focus tools, and habit-breaking features. Everything runs 100% on-device — no servers, no accounts, no ads.

**Logo:** Elegant Urdu Nastaliq calligraphy of فارغ — hand-crafted, flowing, ink-like strokes. Not a font — actual calligraphy art.

**Tagline:** "Free yourself from the noise"

## Design Inspirations
Reference these existing apps for visual direction:
- **TimeZen** — pastel widget cards, illustrated characters, hourly bar charts, app usage pills, mood check-ins, dark + light modes
- **The dark analytics dashboard** (see attached) — glassmorphic dark cards, orange accents, line/bar charts inside stat cards, app icon row
- **Fraud detection dashboard** (see attached) — layered gradient area charts, big hero numbers with sparklines, clean white layout, data-dense but readable
- **The pastel wellbeing app** (see attached) — colored widget cards (pink/blue/purple), illustrated mascots, "Your Time Detoxed" area chart, circular bottom nav

Take what works from all of these and create something that feels uniquely فارغ.

## Vibe
- Modern, sleek, premium — should feel like a $50/year app that's free
- Warm and human, not corporate or clinical
- Data-rich but beautiful — charts and stats should be art, not spreadsheets
- Calm confidence — like a wise friend, not an anxious parent
- The sophistication of Linear meets the warmth of Headspace meets the density of Pi-hole

## Modules (features the app has/will have)
1. App Pause — breathing exercise before opening distracting apps
2. Shorts Blocker — blocks YouTube Shorts, Instagram Reels, TikTok
3. NSFW Detection — on-device AI content scanning
4. DNS Filter — ad/tracker/telemetry blocking (Pi-hole style)
5. Screen Time Tracker — daily/weekly usage with limits
6. Focus Mode — Pomodoro-style distraction blocking
7. Sleep Mode — bedtime app restrictions
8. App Usage Analytics — per-app opens, session lengths, patterns
9. Notification Filter — batch notifications, quiet hours
10. Doom Scroll Detector — detects excessive scrolling
11. Grayscale Mode — removes color to reduce dopamine
12. Digital Detox Challenges — gamified goals

Each module has its own pastel color, vector illustration, and educational onboarding.

## Screens Needed

### Home Dashboard
Command center. Hero wellbeing score, module cards grid, app icon monitoring row, activity chart, quick stats. Should feel alive with data.

### Tracking / Analytics
The most impressive screen. Comprehensive data dashboard with: screen time charts, per-app usage breakdowns with real app icons, DNS blocking stats (queries, block rate, categories, top domains), intervention success rates, pattern insights, weekly trends. Think Pi-hole admin panel but beautiful.

### Modules
Browse all available modules. Each as a card with illustration, name, toggle. Tapping opens detail with settings and module-specific stats.

### Settings
Theme picker (6 themes with visual previews), module configuration sliders, permissions, goals (screen time limit, bedtime), privacy/data, about section with فارغ logo.

### Onboarding (5 pages)
Welcome with illustration + logo → features overview → permissions setup → module selection → goal setting. Swipeable, illustrated, educational.

### Intervention Overlays
- App Pause: dark calming screen, animated breathing circle, timer, then decision buttons
- NSFW Detection: warning with shield illustration, conscious choice buttons
- Both should feel calming, not alarming

### Module Onboarding (4 swipeable cards per module)
What is it → How it works locally → Why it matters (with research) → Enable it
